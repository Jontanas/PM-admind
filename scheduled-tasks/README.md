# Scheduled tasks — retired in v2.0.1

`calendar-sync` is **on demand** from v2.0.1. It proposes a mapping in the Claude chat and writes to Scoro only after the PM confirms. There are no weekly/daily unattended runs and no Slack DMs.

If you still have the old scheduled tasks from earlier plugin versions, delete them in Claude (**Scheduled tasks**):

- Outlook → Scoro Calendar Sync (Weekly)
- Outlook → Scoro Calendar Sync (Daily)

To sync, ask in chat instead: *"Sync my calendar to Scoro"* or *"Sync this week's meetings"*.
